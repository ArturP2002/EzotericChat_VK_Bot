# Как запустить бота у себя на компьютере и смотреть, что происходит

По умолчанию бот получает сообщения через **Bots Long Poll**: процесс сам опрашивает ВК. Публичный HTTPS и Callback API **не нужны**.

1. Бот крутится на вашем Mac (`python main.py` или Docker).
2. Вы пишете сообществу в личку — в терминале и в файле `logs/bot.log` видно каждое действие.

ЮKassa для первого теста **не нужна**. Хватит бесплатного вопроса и одного бесплатного уточнения.

Туннель (ngrok / cloudflared) понадобится только если тестируете **оплату** (вебхук ЮKassa) или сознательно включаете старый режим `VK_EVENT_MODE=callback`.

---

## Что собрать в `.env` (минимум)

| Переменная | Зачем | Можно отложить |
|---|---|---|
| `VK_TOKEN` | Бот отвечает в личке | нет |
| `VK_GROUP_ID` | Числовой id сообщества | желательно |
| `VK_EVENT_MODE` | `longpoll` (по умолчанию) или `callback` | да |
| `DEEPSEEK_API_KEY` | Живые ответы по Системе | да, если `LLM_STUB=true` |
| `ADMIN_VK_ID` | Вам приходят отзывы на одобрение | да, пока не тестируете отзывы |
| `COMMUNITY_CHAT_URL` | Кнопка «Общение» | да |
| `COMMUNITY_CHAT_PEER_ID` | Публикация одобренных отзывов в беседу | да |
| `YOOKASSA_*` | Оплата 100 ₽ | да |
| `VK_SECRET` / `VK_CONFIRMATION` | Только для `VK_EVENT_MODE=callback` | да |

Ниже — откуда взять каждую строку.

## 1. Сообщество ВКонтакте

1. Откройте [vk.com/groups](https://vk.com/groups) → **Создать сообщество**.
2. Тип: **Тематическое сообщество** или **Бизнес**. Название любое, например «Новая Игра — тест».
3. Когда сообщество создано, откройте его. В адресе будет одно из:
   - `https://vk.com/club123456789` — тогда `VK_GROUP_ID=123456789`
   - `https://vk.com/public123456789` — то же число
   - `https://vk.com/короткое_имя` — тогда id смотрите так: откройте любую запись, в ссылке будет `wall-123456789_1`. Число **без минуса** — это id. Минус в ссылке стены значит «это сообщество», в `.env` пишем только цифры.

Свой личный id (для `ADMIN_VK_ID`): откройте свою страницу, в адресе `vk.com/id123` это 123. Если стоит короткое имя — загляните в [vk.com/settings](https://vk.com/settings), блок «Адрес страницы», или откройте «Редактировать» — id виден в ссылках фото.

## 2. Сообщения сообщества и ключ `VK_TOKEN`

В сообществе:

1. **Управление** → **Сообщения** → включите **Сообщения сообщества**.
2. Там же включите **Возможности ботов**.
3. **Управление** → **Настройки** → **Работа с API** (иногда пункт называется **Ключи доступа**).
4. **Создать ключ**.
5. Отметьте доступ **Сообщения сообщества** (и при необходимости «Управление сообществом» не нужен).
6. Подтвердите, скопируйте длинную строку — это `VK_TOKEN`. Ключ показывают один раз, храните в `.env`, никуда не публикуйте.

Проверка: с компьютера можно написать сообществу. Пока бот не запущен, ответа не будет — это нормально.

### Long Poll API в сообществе

При старте бот сам вызывает `groups.setLongPollSettings` (включает Long Poll и события `message_new` / `message_event`).

Если в журнале ошибка про Long Poll — включите вручную:

1. Сообщество → **Управление** → **Работа с API** → вкладка **Long Poll API**.
2. Включите Long Poll.
3. Типы событий:
   - **Входящее сообщение** (`message_new`)
   - **Действие с сообщением** (`message_event`) — без этого нажатия inline-кнопок не дойдут до бота.

**Важно:** не держите одновременно активный Callback API-сервер и Long Poll на одни и те же события — сообщения могут обрабатываться дважды. При Long Poll серверы Callback API в настройках сообщества лучше удалить или выключить.

`VK_SECRET` и `VK_CONFIRMATION` в режиме `longpoll` **не нужны**.

## 3. Ключ DeepSeek (`DEEPSEEK_API_KEY`)

1. Зарегистрируйтесь на [platform.deepseek.com](https://platform.deepseek.com).
2. Пополните баланс (для тестов хватает небольшой суммы; модель дешёвая).
3. **API Keys** → **Create API Key**.
4. Строка вида `sk-...` — в `.env` как `DEEPSEEK_API_KEY`.

Чтобы проверить кнопки и лимиты **без** DeepSeek, поставьте:

```env
LLM_STUB=true
```

Бот будет отвечать заготовленным текстом. Для проверки Системы потом верните `false` и живой ключ.

Модель по умолчанию: `deepseek-chat`. Менять не обязательно.

## 4. Остальное — по желанию

**`ADMIN_VK_ID`** — ваш числовой id. Один раз напишите сообществу с этого аккаунта (ВК не даёт боту писать первым). Иначе отзывы вам не придут.

**`COMMUNITY_CHAT_URL`** — беседа сообщества → три точки → пригласительная ссылка. Пока пусто, кнопка «Общение» честно скажет, что ссылки нет.

**`COMMUNITY_CHAT_PEER_ID`** — числовой `peer_id` той же беседы, обычно `2000000000 + номер_чата` (первый чат сообщества часто `2000000001`). Нужен, чтобы после одобрения отзыв ушёл в беседу анонимно. Сообщество-бот должно состоять в этой беседе.

**ЮKassa** для локального теста не обязательна. Когда будете готовы:

1. Кабинет [yookassa.ru](https://yookassa.ru) → тестовый магазин.
2. `shopId` → `YOOKASSA_SHOP_ID`, секретный ключ → `YOOKASSA_SECRET_KEY`.
3. HTTP-уведомления: нужен публичный HTTPS на `/yookassa/webhook` (см. раздел про туннель ниже).
4. Тестовые карты ЮKassa, не боевая карта.

## 5. Запуск и куда смотреть

База — PostgreSQL. Удобнее всего через Docker.

### Вариант А. Всё в Docker

```bash
cd /Users/arturprotasov/PycharmProjects/EzotericChat_VK_Bot
# заполните .env
docker compose up --build
```

### Вариант Б. Postgres в Docker, бот локально

```bash
cd /Users/arturprotasov/PycharmProjects/EzotericChat_VK_Bot
docker compose up -d db
source .venv/bin/activate
pip install -r requirements.txt
# заполните .env (DATABASE_URL уже указывает на localhost:5432)
python main.py
```

Второй терминал с туннелем **не нужен**, пока не тестируете оплату.

При старте должно быть примерно:

```text
=== Бот «Новая Игра» запускается ===
Токен ВК: задан
События ВК: Bots Long Poll (туннель для ВК не нужен)
ИИ: DeepSeek, модель deepseek-chat
Оплата: выключена
Файл журнала: logs/bot.log
=== Ожидаю события ВК через Bots Long Poll (сообщество …) ===
```

Пишите сообществу в личку с телефона или с другого окна ВК. В терминале появятся строки:

- `Личка: пользователь 123 написал «...»`
- `Списан бесплатный вопрос...`
- `Запрос к ИИ...`
- `ИИ ответил...`
- `Исходящее пользователю...`

Полный журнал: файл `logs/bot.log`. Он крутится сам (до 5 файлов по 5 МБ).

Более подробно:

```env
LOG_LEVEL=DEBUG
```

и перезапуск бота.

Проверка, что HTTP-сервер жив (health и вебхук ЮKassa), без ВК:

```bash
curl http://127.0.0.1:8080/health
```

## 6. Короткий сценарий проверки

1. Написать «привет» — бот сразу спросит, что в жизни просит внимания.
2. Написать ситуацию («не могу уволиться, боюсь») — подробный разбор, в конце «Если хотите, могу…» и кнопки.
3. Написать уточнение следующим сообщением — бесплатно один раз.
4. Ещё одно уточнение без ключей ЮKassa — ссылка «Оплатить» и в тесте кнопка «Проверить платёж»; после проверки сразу ответ на уже написанный текст.
5. «Выход», затем новый текст — это уже новый вопрос (если бесплатный ещё не потрачен — нет; после шага 2 он потрачен).
6. Смотреть `logs/bot.log`: списание кредитов, вызовы ИИ, ошибки отправки.

Витрина сообщества (название, «О сообществе», выключить «Начать») настраивается в кабинете ВК, не в боте. Поле «Сообщение» и фразу про администраторов ВК не даёт сменить.

Если ответа нет: сначала журнал, затем Long Poll включён в сообществе, включено ли событие «Входящее сообщение», жив ли процесс `python main.py`.

## 7. Туннель — только для оплаты или Callback

### Оплата (ЮKassa)

ЮKassa должна достучаться до вашего Mac. Поднимите туннель на порт 8080 и укажите в кабинете:

```text
https://ВАШ-ТУННЕЛЬ/yookassa/webhook
```

### Вариант А. ngrok

```bash
ngrok config add-authtoken ВАШ_ТОКЕН
ngrok http 8080
```

### Вариант Б. Cloudflare Tunnel

```bash
brew install cloudflared
cloudflared tunnel --url http://localhost:8080
```

### Старый режим Callback API

Если по какой-то причине нужен именно Callback:

```env
VK_EVENT_MODE=callback
VK_SECRET=ваш_секрет
VK_CONFIRMATION=строка_из_вк
```

1. Туннель на 8080.
2. В ВК: **Callback API** → адрес `https://ВАШ-ТУННЕЛЬ/vk/callback`.
3. Строку подтверждения — в `VK_CONFIRMATION`, секрет — в `VK_SECRET`.
4. События: входящее сообщение и действие с сообщением.
5. Long Poll при этом лучше выключить, чтобы не было двойной обработки.

Для обычной локальной разработки это **не нужно** — хватает `VK_EVENT_MODE=longpoll`.

## Типичные ошибки

| Что видите | Что сделать |
|---|---|
| Сообщения не приходят в лог | Бот запущен, Long Poll включён, есть `message_new` |
| Сообщения доходят в лог, ответа в ВК нет | Ключ с правом «Сообщения», вы сами написали сообществу первым |
| Кнопки не работают | В Long Poll включено «Действие с сообщением» (`message_event`) |
| Ошибка включения Long Poll через API | Включить Long Poll вручную во вкладке Long Poll API |
| `ИИ: ключ DeepSeek не задан` | Либо ключ, либо `LLM_STUB=true` |
| Оплата не засчитывается | Туннель жив, в ЮKassa указан `/yookassa/webhook` |
| Отзыв «ушёл», вам тишина | Задать `ADMIN_VK_ID` и один раз написать боту с этого аккаунта |
| Двойные ответы | Не держать Callback API и Long Poll одновременно |
