# VK-бот «Новая Игра»

Личный консультант в сообщениях сообщества ВК. Человек описывает трудную ситуацию, бот разбирает её через авторскую Систему «Новая Игра» (О.А. Глухова) с помощью DeepSeek. Общий чат сообщества — только для общения людей между собой.

Тестовый запуск: первый вопрос и одно уточнение бесплатно, дальше 100 ₽ через ЮKassa.

**Как получить ключи и запустить бота на своём компьютере, чтобы писать ему в ВК и смотреть журнал — в [docs/lokalnyi-zapusk.md](docs/lokalnyi-zapusk.md).**

## Как это устроено

- Сообщество ВК — витрина: описание «О сообществе», ссылка «написать боту», ссылка в «Общий чат».
- Личка сообщества — сам продукт. Бот отвечает только здесь и сразу просит рассказать, что просит внимания.
- Кнопка «Общение» открывает беседу. Бот в беседе не отвечает на сообщения людей, но может анонимно публиковать одобренные отзывы.
- Отзыв по кнопке «Отзыв» уходит администратору. После одобрения начисляется бонусный вопрос, отзыв может появиться в общем чате без имени.

## Запуск

### Docker (рекомендуется)

```bash
cp .env.example .env
# заполните ключи — см. docs/lokalnyi-zapusk.md
docker compose up --build
```

Поднимутся Postgres и бот. Порт бота: `8080`.

Только база (бот запускаете сами через `python main.py`):

```bash
docker compose up -d db
```

### Без Docker-образа бота

```bash
docker compose up -d db
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# заполните ключи — см. docs/lokalnyi-zapusk.md
python main.py
```

Проверка, что процесс жив: `curl http://127.0.0.1:8080/health` → `{"status":"ok"}`.

По умолчанию события ВК идут через **Bots Long Poll**: туннель и Callback API не нужны. Достаточно `VK_TOKEN` (и желательно `VK_GROUP_ID`), затем `python main.py` — и можно писать сообществу в личку.

HTTPS-туннель нужен только для вебхука ЮKassa (тест оплаты) или если в `.env` стоит `VK_EVENT_MODE=callback`.

Локально без модели: в `.env` поставьте `LLM_STUB=true`. Ответы будут заглушкой, сценарий кнопок и лимитов проверяется.

Без ключей ЮKassa оплата выключена: после бесплатного входа бот так и напишет.

## Журнал

Все события пишутся на русском: вход в личку, кнопки, списание кредитов, запросы к ИИ, оплата, ошибки.

- Консоль — окно, где запущен `python main.py` / `docker compose up`
- Файл `logs/bot.log` (ротация: 5 файлов по 5 МБ)

Уровень: `LOG_LEVEL=INFO` или `DEBUG` в `.env`. Токены и секреты в журнал не попадают.

## Переменные `.env`

| Переменная | Смысл |
|---|---|
| `VK_TOKEN` | Ключ сообщества с правом сообщений |
| `VK_EVENT_MODE` | `longpoll` (по умолчанию) или `callback` |
| `VK_SECRET` | Секрет Callback API (только для `callback`) |
| `VK_CONFIRMATION` | Строка подтверждения Callback API (только для `callback`) |
| `VK_GROUP_ID` | Числовой id сообщества |
| `DEEPSEEK_API_KEY` | Ключ DeepSeek |
| `DEEPSEEK_MODEL` | По умолчанию `deepseek-chat` |
| `LLM_STUB` | `true` — без реального ИИ |
| `YOOKASSA_SHOP_ID` / `YOOKASSA_SECRET_KEY` | Магазин ЮKassa. Пусто = оплата выключена |
| `YOOKASSA_RETURN_URL` | Куда вернуть человека после оплаты, обычно `https://vk.com/im` |
| `ADMIN_VK_ID` | Ваш числовой id ВК. Нужно один раз написать сообществу, иначе бот не сможет прислать отзыв |
| `COMMUNITY_CHAT_URL` | Ссылка-приглашение в беседу «Общий чат» |
| `COMMUNITY_CHAT_PEER_ID` | `peer_id` беседы (например `2000000001`) для публикации одобренных отзывов |
| `PRICE_RUB` | Цена тестового запуска, 100 |
| `DATABASE_URL` | PostgreSQL, по умолчанию `postgresql+psycopg2://novaigra:novaigra@localhost:5432/novaigra` |
| `LOG_LEVEL` | `DEBUG` / `INFO` / `WARNING` / `ERROR` |
| `LOG_DIR` | Папка журнала, по умолчанию `logs` |
| `LOG_TO_FILE` | `true` — писать ещё и в файл |

## Сообщество ВК (витрина, не код бота)

Это делается вручную в кабинете сообщества. Бот эти экраны не меняет.

1. Название: **Управление → Информация → Название**.
2. Длинное вступление — в **Управление → Информация → Описание**. На странице группы оно видно как «О сообществе». В личку бот его больше не присылает.
3. **Управление → Сообщения** — выключить кнопку «Начать».
4. Поле ввода «Сообщение» и карточка «его увидят администраторы сообщества» — системный текст ВК, его сменить нельзя.
5. Привяжите беседу «Общий чат». Ссылку-приглашение — в `COMMUNITY_CHAT_URL`. Чтобы одобренные отзывы публиковались туда анонимно, задайте `COMMUNITY_CHAT_PEER_ID` (вид `2000000001`) и добавьте сообщество в беседу.

Первое сообщение бота в личке:

```
Расскажи, что сейчас в твоей жизни просит внимания и нового взгляда: отношения, здоровье, финансы ... Можно коротко, можно подробно — как само пойдёт. Я рядом.
```

## ЮKassa

Нужен магазин на ИП, ООО или самозанятого, оферта и чеки 54-ФЗ.

В кабинете ЮKassa:

- HTTP-уведомления: `https://<домен>/yookassa/webhook`
- Событие успешного платежа

После оплаты, если человек уже написал вопрос, бот сразу отвечает. Ссылка одноразовая и привязана к действию. Пока платёж висит, бот присылает ту же ссылку. Кнопка «Проверить платёж» есть только в тестовом режиме без ключей ЮKassa.

## Кнопки

После ответа:

- **Новый вопрос** / **Новый вопрос (100 ₽)** — красная
- **Общение**
- **Выход** — обычный цвет
- **Отзыв** — если нет отзыва на проверке и не было бонуса за последнюю неделю

Уточнение — просто следующим сообщением, без отдельной кнопки. Одно бесплатное, дальше 100 ₽; после оплаты сразу ответ на уже написанный текст.

В конце каждого ответа ИИ добавляет блок «Если хотите, могу помочь:» и 2–3 нумерованных пункта. Кнопки под сообщением остаются.

Администратору на отзыв приходят кнопки **Одобрить** / **Отклонить**. При одобрении отзыв может уйти в общий чат анонимно.

## Система для ИИ

Канон лежит в [`prompts/system_nova_igra.md`](prompts/system_nova_igra.md). Файл в чат не публикуется. В ответах пользователю названия Кодов не используются.

## Проверки

```bash
pytest
```

Эталонный запрос: «не могу уволиться, боюсь». Ответ должен идти через путь и дорогу, фильтр восприятия, страх как механизм отдельности и цикл «встретил — понял — отпустил», без слова «Код» и без приказа «увольняйся / оставайся».
